# Simulation-Based Inference with Normalizing Flows

A machine-learning project exploring **simulation-based inference (SBI)** with the [`sbi`](https://github.com/sbi-dev/sbi) Python framework and neural posterior estimation using normalizing flows.

The project is organized around two complementary inference problems:

1. **Bayesian linear regression** — a controlled benchmark with an analytical posterior and MCMC reference.
2. **Gravitational-wave inference** — an application to a simplified gravitational-wave simulator, where the goal is to recover physical model parameters from simulated observations.

The linear-regression problem provides a simple setting for understanding and validating the SBI workflow before applying the same methodology to a physics-based simulator.

---

## Project Overview

Simulation-based inference is useful when the forward model or simulator can generate data, but evaluating an explicit likelihood is difficult, expensive, or unavailable.

This project focuses on **Neural Posterior Estimation (NPE)**. A conditional density estimator, implemented with a normalizing flow, is trained on simulated parameter–observation pairs and then used to approximate the posterior distribution of model parameters given observed data.

---

### 1. Bayesian Linear Regression

`sbi_linear_regression.ipynb`

The first notebook uses a simple linear model as a controlled test case for SBI.

The notebook:

- defines a linear forward simulator with observational noise,
- samples model parameters from prior distributions,
- generates simulated observations,
- derives and evaluates the analytical posterior,
- uses MCMC as a reference inference method,
- trains a Neural Posterior Estimator with `sbi`,
- compares the learned posterior with the analytical and MCMC results,
- explores how the inference changes under different simulation and data settings.

Because the analytical solution is available, this problem provides a useful baseline for understanding the behaviour and reliability of simulation-based inference.

### 2. Gravitational-Wave Inference

`sbi_gravitational_waves.ipynb`

The second notebook applies the SBI workflow to a simplified gravitational-wave simulator.

The notebook:

- defines a frequency-domain toy gravitational-wave model,
- samples physical parameters from prior distributions,
- generates simulated waveforms,
- trains an NPE model using a normalizing-flow posterior estimator,
- performs posterior inference for simulated observations,
- visualizes the resulting posterior distributions,
- examines the relationship between simulated signals and inferred parameters.

The waveform model uses two parameters, including the logarithm of the signal amplitude and the coalescence time.

This notebook demonstrates how the same SBI methodology can be transferred from a simple benchmark problem to a physics-based simulator.

## Methods

### Simulation-Based Inference

Instead of requiring an explicitly evaluated likelihood,

\[
p(\theta \mid x) \propto p(x \mid \theta)p(\theta),
\]

SBI learns the posterior from simulations generated by a forward model.

Here:

- `θ` represents the model parameters;
- `x` represents simulated observations;
- the simulator maps parameters to observations;
- the neural density estimator learns an approximation to `p(θ | x)`.

### Neural Posterior Estimation

The project uses **Neural Posterior Estimation (NPE)** through the `sbi` framework.

A conditional normalizing flow is trained on simulated parameter–observation pairs. After training, the estimator can generate posterior samples conditioned on an observed dataset.

### Validation

The linear-regression notebook provides two reference approaches:

- an analytical posterior,
- Markov Chain Monte Carlo (MCMC).

These provide independent baselines against which the learned SBI posterior can be examined.
